# Rocket Blast Game 🚀

Rocket Blast is a responsive space shooter game built with **HTML, CSS, and JavaScript**, playable on both desktop and mobile devices. Navigate your spaceship, shoot asteroids, and aim for the highest score!

## 🎮 Features

- Smooth ship movement with mouse, keyboard, and touch controls
- Dynamic asteroids with two types of rocks
- Bullet firing with collision detection
- Explosion animation on asteroid destruction
- Score counter
- Game Over logic when an asteroid hits the ship
- Mobile-friendly responsive design

- HTML5
- CSS3 (responsive design)
- JavaScript (ES6+)
- DOM manipulation & animations

## 👨‍💻 How to Play

- Move Ship: Mouse drag / Arrow keys / Touch drag
- Fire Bullet: Click / Space bar / Tap
- Goal: Destroy asteroids and avoid collision. Survive as long as possible to achieve a high score.
